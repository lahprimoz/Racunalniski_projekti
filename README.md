# Racunalniski_projekti
Repozitorij za objavljanje raznih krajših projektov, ustvarjenih pri računalniških predmetih.

## Seznam projektov

### 1. Pregled računalništva v OŠ v Združenem kraljestvu
* Krajša predstavitev pri predmetu IKT za poučevanje računalništva v 2. letniku
* Pregled in predstavitev kurikuluma za računalniške predmete v Združenem kraljestvu

### 2. Fizična topologija omrežja
* Domača naloga pri predmetu Računalniške komunikacije v 3. letniku
* Shema fizične topologije domačega omrežja
* Pripravljeno z uporabo programa smartdraw
